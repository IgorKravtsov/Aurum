# Aurum CLI

Перед использованием Aurum CLI загрузите актуальные инструкции установленной версии:

```bash
aurum skills get core
```

Для полного перечня команд, полей и допустимых значений используйте:

```bash
aurum skills get core --full
```

Не полагайтесь на сохранённую копию полного справочника: возможности CLI и API меняются вместе с установленной версией.

Перед созданием операций из выписки, файла или другого внешнего источника обязательно получите из Aurum все существующие операции соответствующего счёта за весь импортируемый период и сопоставьте с ними каждую входящую запись. Разделите записи на уже внесённые, вероятные дубликаты, отсутствующие и неоднозначные; не создавайте ничего до показа результатов пользователю и его явного подтверждения. Вносите только подтверждённые отсутствующие записи.
