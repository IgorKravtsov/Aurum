# Схема Postgres заморожена при переходе на Rust, миграции продолжаются от головы Alembic

При переписывании бэкенда на Rust схема базы остаётся байт-в-байт той, что даёт последняя миграция Alembic, а Rust-миграции начинаются с baseline на этой голове. Так существующие self-hosted инсталляции обновляются заменой образа, без дампа и восстановления, а файлы бэкапа JSON совместимы в обе стороны между Python- и Rust-версиями.

## Consequences

- Неудачные имена таблиц/колонок, унаследованные от SQLAlchemy-моделей, сохраняются намеренно — их «исправление» требует отдельной миграции и отдельного решения.
- Alembic удаляется вместе с Python-бэкендом только после того, как baseline проверен на базе, созданной Alembic.
