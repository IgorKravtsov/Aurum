# Обновления

## 2026-11-01 — 1.4.0

- К расходным и доходным операциям можно прикреплять товарные позиции чека: название, количество, единицу измерения, цену за единицу, скидку, итог строки и необязательную категорию. Позиции не обязаны в сумме совпадать с суммой операции — частичный чек допустим, а API возвращает `items_total`, чтобы показать расхождение; строки возврата залога могут быть отрицательными. Позиции независимы от разбиения по категориям и запрещены у переводов.
- Добавлены таблица `transaction_items` и миграция Alembic; позиции поддерживаются при создании, массовом импорте и изменении операций (без поля `items` набор не меняется, переданный список полностью его заменяет, `[]` очищает), а поиск по операциям находит их и по названиям товаров.
- Добавлен отчёт `GET /reports/item-spending`: расходы по товарам, сгруппированные по названию без учёта регистра и лишних пробелов, с общей суммой, количеством, самой частой единицей, числом покупок, средней ценой за единицу и датой последней покупки, фильтрами по периоду, подстроке, счёту и лимиту; суммы пересчитываются в валюту настроек по историческому курсу.
- Резервные копии включают позиции чеков; старые бэкапы без них по-прежнему импортируются.
- В форму операции добавлен сворачиваемый раздел «Позиции чека» с автоматическим расчётом суммы строки, выбором категории и показом разницы с суммой операции; в списке операций появился значок с числом позиций и окно их просмотра; в «Отчётах» появилась вкладка «Товары» с поиском и таблицей на компьютере и карточками на телефоне.
- Aurum CLI получил команду `aurum reports item-spending`, а встроенный skill, полный справочник, README и DOCS.md описывают формат `items`, поле `items_total` и новый отчёт.

## 2026-09-13 — 1.3.2

- Добавлен скрипт `install-cli-pi-srv.sh`, который упаковывает текущую версию Aurum CLI, устанавливает её и обновляет discovery-skill на сервере по SSH без `sudo`.
- Инструкции Aurum CLI теперь требуют перед импортом выписки полностью сопоставить её с существующими операциями, показать найденные дубликаты и неоднозначные записи и вносить только подтверждённые отсутствующие операции.
- Служебная проверка Basic Auth теперь всегда отвечает `204` и передаёт состояние через заголовок, поэтому ожидаемое состояние выхода больше не засоряет консоль браузера ошибками `403`.

## 2026-09-13 — 1.3.1

- В нижнюю часть боковой навигации добавлена кнопка выхода, очищающая текущую и сохранённую авторизацию; действие доступно в развёрнутом, свёрнутом и мобильном меню.

## 2026-09-13 — 1.3.0

- В форму входа добавлена адаптивная кнопка показа и скрытия пароля с локализованными подписями и поддержкой экранных дикторов.
- Объединены параллельные ветки миграций Alembic для сетей криптоактивов и исторических валютных курсов; backend снова автоматически запускается через `alembic upgrade head` как на существующей, так и на новой базе данных.
- Добавлены публичные версионированные multi-platform Docker-образы backend и web для `linux/amd64` и `linux/arm64` в Docker Hub и сценарий развёртывания через `docker compose pull` без локальной сборки; все пароли по-прежнему задаются только на сервере во время запуска.
- Добавлен проектный skill `publish-to-docker-hub` с проверкой истории Git на секреты, защитой неизменяемых версионных тегов, multi-platform сборкой, публикацией и проверкой анонимного доступа к образам.

## 2026-09-12 — 1.3.0

- Добавлен отдельный Node.js CLI `aurum`, покрывающий все endpoint'ы бэкенда именованными командами и универсальной командой `request`.
- Реализована передача JSON-тел через флаги, `--data`, `--file` и `--field`, а ответов — в stdout или защищённый файл через `--output`.
- Добавлена постоянная локальная настройка удалённого API через `aurum config set api-base-url`, разовые переопределения через `--api-base-url` / `AURUM_API_BASE_URL` и поддержка HTTP Basic Auth без хранения паролей в репозитории.
- Добавлены встроенные, соответствующие версии CLI инструкции `aurum skills get core` и полный справочник через `--full`.
- Добавлен `install-skill.sh`, устанавливающий компактный discovery-скилл в `~/.agents/skills` и `~/.claude/skills`.
- CLI оставлен вне Docker-контекстов backend и frontend; добавлены автоматические тесты, проверяющие покрытие всех API-маршрутов.

## 2026-09-11 — 1.2.0

- Удалена зависимость временных UI-идентификаторов от `crypto.randomUUID`, чтобы интерфейс работал при открытии по HTTP через IP-адрес локальной сети.
- Перенесено исправление зависания входа: отдельная проверка Basic Auth без системного диалога браузера и E2E-сценарий входа.
- Добавлена историческая конвертация валют через NBP с локальным кешем курсов и пересчётом финансовых сводок.
- При переносе сохранены существующие доработки безопасности: проверка Host, TLS-конфигурация, аудит и ограничения входных данных.
