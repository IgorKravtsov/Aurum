# Обновления

## 2026-09-13 — 1.3.0

- Объединены параллельные ветки миграций Alembic для сетей криптоактивов и исторических валютных курсов; backend снова автоматически запускается через `alembic upgrade head` как на существующей, так и на новой базе данных.
- Добавлены публичные версионированные Docker-образы backend и web в Docker Hub и сценарий развёртывания через `docker compose pull` без локальной сборки; все пароли по-прежнему задаются только на сервере во время запуска.

## 2026-09-12 — 1.3.0

- Добавлен отдельный Node.js CLI `aurum`, покрывающий все endpoint'ы бэкенда именованными командами и универсальной командой `request`.
- Реализована передача JSON-тел через флаги, `--data`, `--file` и `--field`, а ответов — в stdout или защищённый файл через `--output`.
- Добавлена постоянная локальная настройка удалённого API через `aurum config set api-base-url`, разовые переопределения через `--api-base-url` / `AURUM_API_BASE_URL` и поддержка HTTP Basic Auth без хранения паролей в репозитории.
- Добавлены встроенные, соответствующие версии CLI инструкции `aurum skills get core` и полный справочник через `--full`.
- Добавлен `install-skill.sh`, устанавливающий компактный discovery-скилл в `~/.agents/skills` и `~/.claude/skills`.
- CLI оставлен вне Docker-контекстов backend и frontend; добавлены автоматические тесты, проверяющие покрытие всех API-маршрутов.

## 2026-09-11 — 1.2.0

- Удалена зависимость временных UI-идентификаторов от `crypto.randomUUID`, чтобы интерфейс работал при открытии по HTTP через IP-адрес локальной сети.
- Перенесено исправление зависания входа: отдельная проверка Basic Auth без системного диалога браузера и E2E-сценарий входа.
- Добавлена историческая конвертация валют через NBP с локальным кешем курсов и пересчётом финансовых сводок.
- При переносе сохранены существующие доработки безопасности: проверка Host, TLS-конфигурация, аудит и ограничения входных данных.
